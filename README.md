# 阵地突围

《阵地突围》是一款浏览器端俯视角军事战术射击游戏，包含普通闯关、训练场、丧尸模式、战线模式和同机双人战线模式。

## 在线游玩与下载

- [在线运行最新版本](https://xtltt56-cmd.github.io/zhen-di-tu-po/)
- [下载最新 Windows 游戏包（ZIP）](https://github.com/xtltt56-cmd/zhen-di-tu-po/releases/latest/download/zhen-di-tu-po-latest.zip)
- [查看所有版本与更新记录](https://github.com/xtltt56-cmd/zhen-di-tu-po/releases)

每次 `main` 分支有新的提交时，GitHub Actions 会从当前根目录源码重新生成可运行 ZIP，并更新上面的“最新版本”下载地址，同时部署 GitHub Pages。因此用户不需要下载旧的 `release/` 快照来获取新版本。

## 快速开始

直接双击根目录的 `启动阵地突围.bat`，或用浏览器打开 `index.html`。

如果需要使用可分发版本，请下载上方最新 Windows 游戏包，解压后运行其中的 `启动阵地突围.bat`。

## 出战准备

选择模式或关卡后，先查看出战准备页中的任务目标、开局信息、可用单位及操作提示，再点击“确认出战”或按 Enter 进入战斗。按 Esc 或点击返回可回到首页；从选关进入时会回到原选关界面。准备期间不会推进战斗，也不会购买或生成部队。

同机双人模式由红方按 Enter、蓝方点击“蓝方点击准备”分别确认；双方都准备好后才开始计时与获得收入。单方准备后可以再次操作取消。重开对局也会重新等待双方准备。

战役准备页会显示各关固定的进入点、关键地标、主路线和撤离点，但不会预先生成随机障碍或敌军；其余模式仍显示各自的战场关系示意。准备页读取现有游戏配置，不额外更改兵种数值、价格、关卡限制或存档。

## 战役导航与通路

普通闯关的九关均有固定主路线与两处可辨认地标。随机掩体不会封住主路线，关卡生成后会检查进入点、两处地标和撤离点之间是否存在满足主战坦克碰撞半径的通路；与建筑重叠的敌军和补给会重新放到可站立位置。战斗 HUD 显示当前追踪目标的方向和直线距离，小地图标出路线；任务完成后追踪目标切换为撤离点。训练场、丧尸和战线模式的玩法不受这套战役导航规则影响。

可运行 `node tools/test_campaign_navigation.js` 对九关尺寸进行随机布局与封路回归检查。

## 项目结构

战斗界面：普通战役、训练场与丧尸模式共用新的 HUD。底部展示全部六种步兵武器，Q/E 单次按键循环切换，数字 1–6 直接选择；换弹进度显示在正在装填的武器格上。驾驶悍马时仍使用乘员枪械，驾驶坦克时改为显示 3/4/5 主炮弹种、装填与防御状态。暂停和出战准备期间不会切换玩家武器。

- `index.html`：游戏入口、关卡与 Canvas 运行层。
- `src/`：性能、音频、存档、设置、寻路、战斗反馈和战线双人模式等模块。
- `assets/`：人物、载具、建筑、地形和界面素材。
- `assets/environment-v5/`：战场场景素材；战役、训练场与丧尸模式使用俯视物件，单人/双人战线共用侧视背景。
- `tools/`：平衡分析、回归检查和可视化验证脚本。
- `output/`：平衡分析笔记本、设计说明和已生成的验证记录。
- `release/`：历史可分发快照；客户使用请优先下载上方的 latest Release。

`tools/package_game.py` 是无第三方依赖的分发打包脚本；它只复制运行游戏所需的入口、模块和正式素材，不会把测试截图、浏览器缓存或本地临时目录放进客户下载包。

## 说明

本仓库不包含 `tmp/` 和 `.playwright-cli/`，这些目录只保存本地生成缓存、浏览器状态和临时文件，可能包含敏感令牌或不适合发布的运行数据。
